# 📊 SQL Analytics Portfolio

В этом репозитории представлены мои учебные и практические проекты по работе с базами данных. Код демонстрирует умение решать типовые бизнес-задачи аналитика.

### 🛠 Используемые навыки:
- **Базовые запросы:** `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`
- **Агрегация данных:** `GROUP BY`, `SUM`, `COUNT`, `AVG`
- **Объединение таблиц:** `INNER JOIN`, `LEFT JOIN`
- **Продвинутые конструкции:** Обобщенные табличные выражения (`CTE` / `WITH`), оконные функции (`ROW_NUMBER`, `RANK`)

### 📁 Структура проекта:
- `ecommerce_analysis.sql` — скрипт с запросами для анализа продаж интернет-магазина (расчет выручки, детализация заказов, ранжирование менеджеров по месяцам).

*Все запросы снабжены подробными комментариями, объясняющими бизнес-логику каждого шага.*
